# Design Language

## Visual Identity

- Positioning: 小白学 AI 的实践型样本，展示从学习到做出工具系统的路径。
- Archetype: GitHub-native profile command deck + knowledge constellation.
- Primary color: starfield ink `#070b13`.
- Accent colors: electric cyan `#00d9ff`, orbit purple `#9b7cff`, signal amber `#f6a623`, tool green `#00e6a8`.
- Neutral: high-contrast white `#f4f7fb`, muted slate `#8fa1ba`.

## Components

- SVG panels use dark rounded GitHub-native panels, orbit paths, glowing nodes, telemetry columns, and restrained labels.
- README text stays concise and link-heavy; the visuals create memory, the Markdown creates clickability.
- SVG asset names follow the visible module roles: `galaxy-header`, `mission-telemetry`, `tech-stack`, `projects-constellation`.
- The visual README should feel close to the cclank profile structure while keeping the story and project labels original.
- Avoid fake metrics, fake awards, and overclaiming expertise. The story is learning-in-public plus working artifacts.

## Anti-Patterns

- Do not copy cclank paths, labels, colors, or project framing directly.
- Do not use generic purple/blue AI gradients without structural meaning.
- Do not present the profile as a senior expert persona; keep the beginner-to-builder narrative.

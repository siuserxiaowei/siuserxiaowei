# Design Language

## Visual Identity

- Positioning: 小白学 AI 的实践型样本，展示从学习到做出工具系统的路径。
- Archetype: knowledge constellation + research archive + blueprint console.
- Primary color: deep ink green `#07130f`.
- Accent colors: learning green `#00e6a8`, electric blue `#63d8ff`, proof lime `#d8ff6a`.
- Neutral: paper white `#f7f5ea`, muted mint gray `#b8cec5`.

## Components

- SVG panels use dark structured backgrounds, thin coordinate grids, glowing learning nodes, and restrained labels.
- README text stays concise and link-heavy; the visuals create memory, the Markdown creates clickability.
- SVG asset names follow the visible module roles: `intro-lab`, `skill-radar`, `project-map`, `now-shipping`.
- The visual README should feel like a learning lab dashboard, not a copied galaxy theme.
- Avoid fake metrics, fake awards, and overclaiming expertise. The story is learning-in-public plus working artifacts.

## Anti-Patterns

- Do not copy the cclank galaxy artwork directly.
- Do not use generic purple/blue AI gradients.
- Do not present the profile as a senior expert persona; keep the beginner-to-builder narrative.
